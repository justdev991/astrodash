# 🚀 AstroDash - Controllo Missione Spaziale

**AstroDash** è una dashboard interattiva creata per simulare il pannello di controllo di un'astronave in tempo reale. Questo progetto unisce un'estetica sci-fi a una logica di monitoraggio funzionale.

## 🛠️ Funzionalità
- **Monitoraggio Sistemi:** Visualizzazione costante dei livelli di ossigeno, integrità dello scafo e riserve di carburante.
- **Interfaccia Futuristica:** Design ottimizzato con Google Fonts (Orbitron) e uno stile "Neon-Night" ad alto contrasto.
- **Logica Interattiva:** Gestione dinamica degli stati della missione tramite JavaScript.

## 💻 Tecnologie Utilizzate
- **HTML5:** Struttura modulare dei sistemi di bordo.
- **CSS3:** Animazioni, layout flessibile e styling futuristico.
- **JavaScript (ES6+):** Motore di calcolo per i parametri vitali dell'astronave.
